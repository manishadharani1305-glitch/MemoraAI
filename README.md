# 🧠 MemoraAI – Local Memory Chatbot

> A chatbot that remembers.

MemoraAI is a local AI-powered memory chatbot designed to store, retrieve, and use user-provided memories during conversations.

Unlike a normal chatbot that starts every conversation from zero, MemoraAI maintains a local memory vault so that relevant information can be retrieved when needed.

## ✨ Features

- 🧠 Local memory storage
- 💬 AI-powered conversation
- 🔍 Memory retrieval
- 💾 Persistent memory
- 🗑️ Delete individual memories
- 📜 Chat history
- 🔒 Local-first architecture
- ⚡ Simple Streamlit interface
- 🤖 Ollama local AI integration
